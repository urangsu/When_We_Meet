# When We Meet Copy System

## Voice
- 가볍다
- 다정하다
- 부담 없다
- 설렌다
- 명확하다

## Avoid
- 과하게 공식적인 말투
- 업무용 캘린더 같은 표현
- 너무 긴 설명
- 강요하는 CTA
- "참석 필수"처럼 부담 주는 표현

## Preferred Words
- 초대장
- 가볍게
- 같이
- 시간 맞춰보기
- 우리 달력
- 기록 적기
- 사진으로 공유
- 가능하면
- 부담 없이
- 이런 분위기

## Button Copy Rules
Primary CTA:
- 초대장 만들기
- 다음 · 날짜 고르기
- 사진으로 공유
- 이 날짜로 확정하기

Guest CTA:
- 참여할게요
- 아직 모르겠어요
- 이번엔 어려워요
- 가능한 날 고르기

Calendar CTA:
- 기록 적기
- 기록 보기
- 준비 메모
- 후보 메모
- 사진으로 공유

## Invite Copy Examples
- 이번 주말, 같이 시간 맞춰볼까요?
- 날씨 괜찮으면 한강 쪽에서 가볍게 볼까요?
- 편하게 커피 마시면서 잠깐 이야기 나눌까요?
- 시간 맞으면 맛있는 거 먹으러 갈까요?
- 퇴근 후에 부담 없이 잠깐 볼까요?
