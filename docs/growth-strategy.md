# When We Meet Growth Strategy

## Growth Loop
1. Host creates invite card.
2. Host shares image/link in KakaoTalk or DM.
3. Guests open and respond.
4. Guests see product value.
5. Guests later create their own invite.
6. Calendar records improve future recommendations.

## Data Asset Strategy
Useful future signals:
- date preference
- place candidate
- activity preference
- calendar memo tags
- invite copy selection
- region/location hints
- response friction
- confirmed plan

## SEO / Content Expansion

- 이번 주말 어디서 만나?

- 전시/팝업/축제 추천

## Monetization Ideas
- premium invitation themes
- premium image card templates
- local place promotion
- event/festival promotion
- reservation affiliate
- group activity promotion
- photo booth / cafe / dessert partnerships

## Ad Principle
Ads must feel like recommendations, not banners.
Contextual recommendation first, display ads later.
