## Short Description
친구들과의 약속을 날짜, 장소, 활동, 초대장으로 가볍게 정리하세요.

## Full Description
When We Meet은 친구들과의 약속을 더 쉽게, 더 예쁘게 정해주는 초대장 기반 모임 앱입니다.

단톡방에서 가능한 날짜를 묻고, 장소를 다시 정하고, 누가 되는지 다시 찾는 일이 번거로웠다면 When We Meet으로 하나의 초대장을 만들어보세요.

날짜 후보, 만날 곳, 하고 싶은 것, 초대 문구까지 한 번에 정리하고 친구들은 가능한 날을 부담 없이 고를 수 있습니다.

우리 달력에 기록을 남겨두면 다음 약속을 만들 때 장소, 활동, 문구 추천에도 활용할 수 있어요.
