## Problem
단톡방에서 약속 잡기, 왜 이렇게 피곤할까요?

- 가능한 날짜가 흩어져요.
- 장소 이야기가 계속 바뀌어요.
- 누가 되는지 다시 찾아봐야 해요.
- 초대 문구도 은근히 고민돼요.

## Solution
When We Meet은 약속을 하나의 초대장으로 정리합니다.

- 가능한 날짜 고르기
- 만날 곳 정하기 또는 후보 받기
- 만나서 뭐 할지 고르기
- 친구들의 응답 모아보기
- 최종 일정 확정하기
