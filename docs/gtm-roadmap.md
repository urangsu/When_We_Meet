# When We Meet GTM Roadmap

## Phase 1 — Private Beta
Goal: 친구 모임을 자주 만드는 사용자 30~50명 테스트

Focus:
- 초대장 생성 완료율
- 공유율
- 게스트 응답 완료율
- 재사용 의향

## Phase 2 — Social Sharing Loop
Goal: 카톡/DM 공유 카드 기반 자연 유입

## Phase 3 — Local Content SEO
Goal: 장소/활동 추천 콘텐츠 기반 검색 유입 준비

## Phase 4 — Monetization Test
Goal: 프리미엄 테마, 공유 카드 템플릿, 로컬 추천 테스트

## Key Metrics
- invite_create_started
- invite_shared
- invite_opened
- guest_response_completed
- meeting_confirmed
- calendar_record_attached_to_meeting
